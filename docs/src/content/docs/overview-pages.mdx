---
title: Overview Pages
description: Learn which overview pages the Starlight Automatic Overview Pages plugin generates and how they are linked in the sidebar.
---

The Starlight Automatic Overview Pages plugin makes sure every directory of your docs has a page listing its content, and that every sidebar group links to it.

## Generated pages

An overview page is generated for every directory of the `src/content/docs/` directory that contains at least one page and has no page of its own.
For example, the following content generates an overview page at `/guides/` and another one at `/guides/advanced/`:

import { FileTree } from "@astrojs/starlight/components";

<FileTree>

- src/content/docs/
  - index.mdx
  - guides/
    - installation.mdx
    - deployment.mdx
    - advanced/
      - theming.mdx
      - plugins.mdx

</FileTree>

Overview pages use the look of regular pages: the title is the label of the matching sidebar group and the content is a [link card](https://starlight.astro.build/components/link-cards/) for each entry of the group.

- Links to pages display the page [`description`](https://starlight.astro.build/reference/frontmatter/#description) below their label.
- Nested groups link to their own overview page.
- External links and links to pages outside of the directory are included as well.

The [`/demo/`](/demo/) page of this website is an example of a generated overview page.

When a directory already has a page, e.g. `guides/index.mdx` or `guides.mdx`, no page is generated and the link cards are [appended to the existing page](/customization/#add-an-introduction) instead.

Directories only containing pages [hidden from the sidebar](https://starlight.astro.build/reference/frontmatter/#hidden) and directories matching the [`exclude`](/configuration/#exclude) option are ignored.

## Sidebar groups

To find the overview page of a sidebar group, the plugin looks at all the pages the group links to, including the pages of its nested groups.
When all these pages live in the same directory, the overview page of this directory belongs to the group.

This works with [autogenerated links](https://starlight.astro.build/guides/sidebar/#autogenerated-links) and with manual groups whose pages share a directory:

```js {5-6}
starlight({
  sidebar: [
    {
      label: "Guides",
      // All pages are in `src/content/docs/guides/`: the group links to `/guides/`.
      items: ["guides/installation", "guides/deployment"],
    },
    {
      label: "Start Here",
      // Pages from different directories: the group has no overview page.
      items: ["getting-started", "guides/installation"],
    },
  ],
});
```

Every group with an overview page gets an “Overview” link as its first item, unless the group already links to this page or the [`sidebarLink`](/configuration/#sidebarlink) option is disabled.
The overview link is also part of the previous and next page links at the bottom of each page, respecting the [`prev`](https://starlight.astro.build/reference/frontmatter/#prev) and [`next`](https://starlight.astro.build/reference/frontmatter/#next) frontmatter fields of your pages and the [`pagination`](https://starlight.astro.build/reference/configuration/#pagination) option.

Directories that do not match any sidebar group still get an overview page listing their pages in the same order as an autogenerated sidebar group, i.e. sorted by [`sidebar.order`](https://starlight.astro.build/reference/frontmatter/#order) and then alphabetically.

## Link to overview pages

Generated overview pages can be linked like any other page, e.g. `[Guides](/guides/)`.

:::note
Generated overview pages are not part of the `docs` content collection.
If you use the [`starlight-links-validator`](https://github.com/HiDeoo/starlight-links-validator) plugin, add the links to these pages to its [`exclude`](https://starlight-links-validator.vercel.app/configuration/#exclude) option to avoid false positives:

```js
starlightLinksValidator({
  exclude: ["/guides/", "/guides/advanced/"],
});
```

:::

## Multilingual sites

On [multilingual sites](https://starlight.astro.build/guides/i18n/), overview pages are generated for every language.
When a page is not translated yet, the overview page links to its [fallback content](https://starlight.astro.build/guides/i18n/#fallback-content) like the sidebar does.

The label of the overview link in the sidebar is translated in many languages and can be [customized](/customization/#translate-the-sidebar-link).
