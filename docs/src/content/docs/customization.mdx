---
title: Customizing Group Pages
description: Learn how to add an introduction, change the title and adjust the link cards of group pages.
---

Group pages are built from your sidebar configuration and the frontmatter of your pages.
See [“Group Pages”](/group-pages/#content) to learn where each part of a group page comes from.

## Add an introduction

Create an index page for the directory, e.g. `src/content/docs/guides/index.mdx`:

```mdx
---
# src/content/docs/guides/index.mdx
title: Guides
description: Step-by-step guides to get the most out of Starlight Rocket.
---

Start with the installation guide if you are new to Starlight Rocket.
```

The plugin renders your page and appends the link cards of the directory below your content.
The page supports all [frontmatter](https://starlight.astro.build/reference/frontmatter/) fields and [components](https://starlight.astro.build/components/using-components/) of a regular page.
The [Reference](/demo/reference/) demo page uses this approach.

## Change the title

Generated pages use the label of their sidebar group as title.
Change the [group `label`](https://starlight.astro.build/guides/sidebar/#groups) in your `sidebar` configuration, or [add an index page](#add-an-introduction) with the title of your choice.

Nested groups of [autogenerated links](https://starlight.astro.build/guides/sidebar/#autogenerated-links) are labeled with their directory name by Starlight.

## Describe the link cards

Add a [`description`](https://starlight.astro.build/reference/frontmatter/#description) to the frontmatter of a page to display it on its link card:

```md {3}
---
title: Installation
description: Install Starlight Rocket in your project.
---
```

To change the label of a link card, change the label of the sidebar entry, e.g. with the [`sidebar.label`](https://starlight.astro.build/reference/frontmatter/#label) frontmatter field.

## Translate the sidebar link

Add the `starlightGroupPages.sidebarLink` key to your [translation files](https://starlight.astro.build/guides/i18n/#translate-starlights-ui) to change the label of the “Overview” sidebar link or to translate it into a missing language:

```json
// src/content/i18n/en.json
{
  "starlightGroupPages.sidebarLink": "Introduction"
}
```

## Exclude directories

Add the directories to the [`exclude`](/configuration/#exclude) option:

```js
starlightGroupPages({
  exclude: ["reference/**"],
});
```
