---
title: Customization
description: Learn how to add introductions, titles and descriptions to the overview pages generated by the Starlight Automatic Overview Pages plugin.
---

Overview pages are built from content you already have: the labels of your sidebar groups and the frontmatter of your pages.
This guide shows how to adapt them further.

## Add an introduction

To add an introduction, a custom title or any other content to an overview page, create an index page for its directory, e.g. `src/content/docs/guides/index.mdx`:

```mdx
---
# src/content/docs/guides/index.mdx
title: Guides
description: Step-by-step guides to get the most out of Starlight Rocket.
---

These guides walk you through the most common tasks.
Start with the installation guide if you are new to Starlight Rocket.
```

The plugin renders your page as usual and appends the link cards of the directory below your content.
Your page supports everything a regular page supports, like [components](https://starlight.astro.build/components/using-components/) or [frontmatter](https://starlight.astro.build/reference/frontmatter/) options, e.g. to [hide it from the sidebar](https://starlight.astro.build/reference/frontmatter/#hidden) or to change its [`sidebar.label`](https://starlight.astro.build/reference/frontmatter/#label).

The [Reference](/demo/reference/) demo page uses this approach.
To keep the link cards off your index pages, disable the [`extendIndexPages`](/configuration/#extendindexpages) option.

## Describe the link cards

Each link card displays the [`description`](https://starlight.astro.build/reference/frontmatter/#description) of the linked page, which is also used for search engines and social media previews.
Link cards of nested groups display the description of their index page, if any.

```md
---
title: Installation
description: Install Starlight Rocket in your project.
---
```

## Change the title and the card labels

The title of a generated overview page and its link cards use the same labels as the sidebar:

- The label of a group is its [`label`](https://starlight.astro.build/guides/sidebar/#groups) in the `sidebar` configuration. Nested autogenerated groups are named after their directory, e.g. `advanced`.
- The label of a page is its [`sidebar.label`](https://starlight.astro.build/reference/frontmatter/#label) or its title.

To use a different title for a single overview page, [add an index page](#add-an-introduction) with the title of your choice.

## Translate the sidebar link

The plugin provides translations of the “Overview” sidebar link label for several languages.
To change the label or to add a missing language, use the `starlightAutomaticOverviewPages.sidebarLink` key in your [translation files](https://starlight.astro.build/guides/i18n/#translate-starlights-ui):

```json
// src/content/i18n/en.json
{
  "starlightAutomaticOverviewPages.sidebarLink": "Introduction"
}
```

## Skip directories

To skip some directories entirely, use the [`exclude`](/configuration/#exclude) option.
Nested groups of excluded directories are rendered as sections with a heading on the overview page of their parent directory.
