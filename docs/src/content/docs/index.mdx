## Features

<CardGrid stagger>
  <Card title="Overview pages" icon="document">
    Every directory of your docs gets a page listing its content with Starlight
    link cards, using the titles and descriptions of your pages.
  </Card>
  <Card title="Sidebar links" icon="list-format">
    Each sidebar group links to its overview page, so readers can always reach
    the landing page of a section, also with the previous and next page links.
  </Card>
  <Card title="Customizable" icon="pencil">
    Write an index page with an introduction and the plugin appends the link
    cards below it. No new syntax or configuration to learn.
  </Card>
  <Card title="Multilingual" icon="translate">
    Overview pages are generated for every language of your site, with
    translated labels and fallback content for untranslated pages.
  </Card>
</CardGrid>
