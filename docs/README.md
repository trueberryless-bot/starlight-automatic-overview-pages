# `starlight-automatic-overview-pages-docs`

Documentation for the `starlight-automatic-overview-pages` Starlight plugin, deployed at [starlight-automatic-overview-pages.netlify.app](https://starlight-automatic-overview-pages.netlify.app).

## Documentation

Run the documentation locally by running the following command in your terminal:

```shell
pnpm run dev
```

Content can be found in the [`src/content/docs/`](https://github.com/trueberryless-org/starlight-automatic-overview-pages/tree/main/docs/src/content/docs) directory.
